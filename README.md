# ColorPicker

Minimalistic and fast color picker component for Vue.

<img src="./docs/screenshot.png" alt="Color Picker Screenshot" width="50%">
<img src="./docs/colorpicker.gif" alt="Color Picker GIF" width="50%">

## Features

* Conversion color to RGB and HEX models
* Direct text input
* Dynamic color change
* Input validation
* Touch optimization
